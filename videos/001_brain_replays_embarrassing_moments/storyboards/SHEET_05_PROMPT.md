# Video 001 — Storyboard Sheet 05 Prompt

Covers: Beats 17–18

```text
Create a seamless 2x2 storyboard sheet for a faceless YouTube psychology video.

GLOBAL STYLE:
Use the exact same recurring young male character, bedroom, embarrassing-memory motif, and illustrated-cartoon rendering established in the previous sheets.

INVISIBLE CROP LAYOUT:
Create one exact 2x2 quadrant composition on a 16:9 full canvas.
All four quadrants must be equal size and aligned to the exact horizontal and vertical center.
There must be NO visible grid, NO separator lines, NO comic frames, NO boxes, NO panel numbers, and NO corner labels.
Treat the center lines as invisible crop boundaries only.
No important character, prop, memory object, glow, shadow, or effect may cross a crop boundary.
Each quadrant must remain a complete standalone 16:9 composition after a simple 50/50 crop.

TEXT POLICY:
Do not add captions, narration text, subtitles, labels, scene numbers, logos, or watermarks.
Prefer no written text at all.

TOP LEFT — BEAT 17:
Show the recurring embarrassing memory as a clearly defined visual object or floating remembered scene in front of the character. It must remain ordinary in size and unchanged. The character observes it with a calmer, more reflective expression.

TOP RIGHT — BEAT 18:
Keep that exact same memory at the exact same size and visual prominence while the surrounding room becomes quieter, darker, simpler, and emptier. Competing visual noise fades away. The composition should make the final idea instantly clear: the memory did not get bigger; everything around it got quieter.

BOTTOM LEFT — UNUSED:
Keep this quadrant visually neutral and empty. Use only a simple continuation of the background style with no new story content, no character, and no important object.

BOTTOM RIGHT — UNUSED:
Keep this quadrant visually neutral and empty. Use only a simple continuation of the background style with no new story content, no character, and no important object.

CONSISTENCY:
Preserve the exact recurring character and memory appearance from previous sheets.
The final two active quadrants should feel like a visual payoff to the opening bedroom scene.
No visible panel separators, no numbers, and no narration captions.
Every quadrant must remain cleanly crop-safe.
```
