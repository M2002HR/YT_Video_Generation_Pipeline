# Video 001 — Storyboard Sheet 04 Prompt

Covers: Beats 13–16

```text
Create a seamless 2x2 storyboard sheet for a faceless YouTube psychology video.

GLOBAL STYLE:
Use the exact same recurring young male character and the same illustrated-cartoon rendering established in the previous sheets: dark tousled hair, expressive eyes, youthful proportions, cohesive cinematic storybook lighting, and the same recognizable bedroom. Preserve the same embarrassing-memory visual language.

INVISIBLE CROP LAYOUT:
Create one exact 2x2 quadrant composition on a 16:9 full canvas.
All four quadrants must be equal size and aligned to the exact horizontal and vertical center.
There must be NO visible grid, NO separator lines, NO comic frames, NO boxes, NO panel numbers, and NO corner labels.
Treat the center lines as invisible crop boundaries only.
No important character, prop, memory element, glow, comparison element, or effect may cross a crop boundary.
Each quadrant must remain a complete standalone 16:9 composition after a simple 50/50 crop.

TEXT POLICY:
Do not add captions, narration text, subtitles, labels, scene numbers, logos, or watermarks.
Avoid readable text inside the image unless absolutely necessary. Prefer purely visual storytelling.

TOP LEFT — BEAT 13:
Show the exhausted recurring character trying to disengage from the thought loop while a repeating film strip, circular memory path, or visual thought spiral keeps pulling his attention back toward the embarrassing memory. The character should look tired rather than panicked.

TOP RIGHT — BEAT 14:
Create a clear noon-versus-midnight comparison using the exact same embarrassing memory at the exact same visual size in both contexts. One side feels bright and busy, the other dark and quiet. The memory itself must remain visually unchanged; only the surrounding amount of competing stimulation changes.

BOTTOM LEFT — BEAT 15:
Show the same embarrassing memory isolated by itself in a large, mostly empty visual space, like a lone object on a quiet stage after all competing distractions have disappeared. The key idea is less competition, not a physically enlarged memory.

BOTTOM RIGHT — BEAT 16:
Back in the same bedroom at night, show a whimsical archive metaphor: an old filing cabinet, drawer, or collection of stored awkward memories opening near the character. Keep it clearly metaphorical and visually simple. No readable labels are necessary.

CONSISTENCY:
Preserve the same character, bedroom, memory scene, supporting people, clothing identity, palette, and rendering style from previous sheets.
No visible panel separators, no numbers, and no narration captions.
Every quadrant must remain cleanly crop-safe.
```
