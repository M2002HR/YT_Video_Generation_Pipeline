# Video 001 — Storyboard Sheet 03 Prompt

Covers: Beats 09–12

```text
Create a seamless 2x2 storyboard sheet for a faceless YouTube psychology video.

GLOBAL STYLE:
Use the exact same recurring young male character and the same illustrated-cartoon rendering from Sheets 01 and 02: dark tousled hair, expressive eyes, youthful proportions, cinematic illustrated lighting, cohesive storybook style. Preserve the same awkward social memory and the same supporting people when they reappear.

INVISIBLE CROP LAYOUT:
Create one exact 2x2 quadrant composition on a 16:9 full canvas.
All quadrants must be equal size and aligned to exact horizontal and vertical center lines.
No visible grid, no separator lines, no comic frames, no boxes, no panel numbers, and no corner labels.
The center lines are invisible crop boundaries only.
No important object, person, glow, memory bubble, film strip, or effect may cross those boundaries.
Each quadrant must remain a complete standalone 16:9 image after a 50/50 crop.

TEXT POLICY:
No captions, narration text, subtitles, labels, panel numbers, logos, or watermarks.
Avoid speech bubbles unless absolutely necessary; communicate these beats visually.

TOP LEFT — BEAT 09:
Show the embarrassing memory repeating in a loop around the main character, using a clear visual replay metaphor such as repeated film frames or multiple copies of the same awkward moment circling him. The character looks trapped in repetitive mental replay.

TOP RIGHT — BEAT 10:
Close view of the awkward flashback itself. Show the past version of the same character caught mid-sentence in front of the same two or three peers from the recurring memory. Focus on the exact embarrassing moment.

BOTTOM LEFT — BEAT 11:
Show the present-day character imagining exaggerated judging reactions from those same people. Make it visually clear that these reactions are imagined rather than objective reality, for example with translucent or thought-like versions of the peers looking more judgmental than before.

BOTTOM RIGHT — BEAT 12:
Show multiple alternate versions of the awkward moment branching around the character, representing different things he wishes he had said instead. Use visual branching, alternate poses, or multiple versions of the scene. Avoid readable dialogue text; the concept should be understandable through composition.

CONSISTENCY:
Keep the same main character, same flashback clothing, same peers, and same memory setting from earlier sheets.
Maintain the same illustration quality and palette.
No visible panel separators, no numbers, no narration captions.
Every quadrant must remain cleanly crop-safe.
```
