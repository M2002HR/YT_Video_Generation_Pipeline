# Video 001 — Video-Specific References

The global visual identity for this video is selected in `VISUAL_PRESET.md`.

This directory is only for **video-specific recurring references** that should not live in the reusable global preset.

Optional examples:

```text
references/
  bedroom_anchor.png
  memory_anchor.png
  REFERENCE_NOTES.md
```

Use a video-specific anchor when a location, prop set, supporting cast, or recurring flashback must stay stable across multiple storyboard sheets.

Do not duplicate the global style or protagonist anchors here. Those belong to the selected preset under `visual_presets/`.
