# Lazily generated spyglass identity

Do not install a second character sheet here. On the first real spyglass run, the existing `stage_entry_identity` generates `spyglass_design_sheet.png` from `prompts/entry_identity.md`, validates it and stores its canonical `.receipt.json`. Subsequent runs reuse only a valid image and receipt. No asset is generated on imports, catalog loading or preflight.

The identity prompt locks the recurring prop geometry. The episode entry frame receives this identity, the topic-world style and the operator's character sheet; Flow B receives only the resulting entry frame and the host-free world keyframe. As with the orb pipeline, real image consistency is checked on the first paid smoke run, not claimed from offline tests. Never manufacture a receipt for an unreviewed file.
