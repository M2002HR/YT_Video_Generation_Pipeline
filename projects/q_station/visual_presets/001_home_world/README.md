# 001_home_world — neutral Q Station opening treatment

This compatibility-stable preset controls HOW the opening is rendered: simplified hand-drawn 2D educational animation, clean dark contours, readable silhouettes, restrained cel shading and a muted natural palette. It does not define WHO the host is or WHERE an episode opens.

`character_sheet.png` and `source/character_sheet.png` are deprecated pre-registry identity assets retained only for historical compatibility. New runs resolve the selected canonical sheet from `characters/registry.json`. No visual/style sheet is ever uploaded to Flow.
