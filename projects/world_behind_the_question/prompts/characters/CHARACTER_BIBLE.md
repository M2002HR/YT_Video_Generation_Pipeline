# Main Character Bible — Working Identity

**Final character name:** not locked yet  
**Internal role:** The Seeker / recurring protagonist  
**Project:** `world_behind_the_question`

## Personality anchors

- intensely curious without being smug
- intelligent but approachable
- adventurous because questions pull him forward
- notices small details
- enjoys being surprised
- willing to admit uncertainty
- warm, lightly eccentric, never slapstick by default

## Canonical visual anchors

1. youthful original face
2. asymmetric chestnut/dark-brown wavy hair with one loose front curl
3. small rounded, slightly oval warm-brass glasses
4. deep-teal / muted moss outer layer
5. compact crossbody satchel
6. Page Key
7. warm cream + brass/amber secondary accents
8. slim, agile, curious body language

## Thematic wardrobe adaptation

World-specific clothing is encouraged because it makes entering each book feel meaningful. Keep it diluted rather than costume-heavy.

Default target: preserve 70–85% of the core design and adapt 15–30%.

The adaptation should support the subject, not hide the brand character.
