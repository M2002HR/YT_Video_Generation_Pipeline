# Prompt 00 — Episode World Designer

## Purpose

Create one durable visual design bible for the question-specific book world in
this episode of **The World Behind the Question**. Every later visual beat and
image prompt will use this document, so it must make the episode feel like one
coherent journey rather than a collection of unrelated illustrations.

## Core universe

Every meaningful question exists as a discoverable book in the Library of
Living Questions. The canonical Seeker finds the relevant book, opens it, and
crosses into a subject-specific world. That world changes with the question;
the Seeker, Page Key, hand-drawn educational-adventure language, and subtle
library/book motifs preserve channel identity.

The book world must express the actual subject, not merely decorate everything
with books. A question about memory might become an architectural archive; a
question about oceans might become a layered living seascape; a historical
question might become a grounded period world. Choose the strongest visual
logic for this exact episode.

## Requirements

- Base the design only on the supplied brief and final narration.
- Design the opening as a **6–10 second cold-open hook block** driven by the
  narration's most arresting honest topic-specific image or action. It must
  create immediate curiosity before any calm setup.
- Make that hook block visually coherent enough to work now as 2–3 sequential
  still-image beats with lightweight motion, while also being replaceable in a
  future pipeline by one continuous 6–10 second generated video clip. Define a
  clear opening subject, action/tension, camera progression, and transition
  endpoint; do not require captions, dialogue, lip-sync, or on-screen text.
- Make the mandatory episode path concrete without slowing the hook: compelling
  topic-specific cold open → reveal or activation of the question book and
  portal → sustained exploration of the subject world → final payoff → return
  to the Library or a clear book/Page Key echo behind the short CTA.
- Define one clear governing visual metaphor and a coherent physical world.
- Design a topic-specific book artifact: cover material, shape, emblem, page
  behavior, and the visual transition created when it opens.
- Preserve the canonical Library of Living Questions as the home base.
- Preserve the Seeker's recognizable face, hair, small brass glasses,
  teal/moss core outfit, satchel, and Page Key.
- If useful, adapt only 15–30% of the outfit through fabric, trim, or one modest
  accessory suited to the subject world.
- Specify a controlled palette, materials, light, scale, atmosphere, recurring
  locations, recurring props, and transition language.
- Make the world support accurate explanation. Do not visualize an uncertain
  idea as proven fact or invent mechanisms absent from the narration.
- Make it practical for sequential standalone still images with subtle zoom,
  pan, and crop motion.
- Avoid grids, comic panels, captions, logos, UI overlays, and text-dependent
  explanations.
- Do not imitate a named franchise, artist, film, or copyrighted character.
