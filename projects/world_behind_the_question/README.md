# The World Behind the Question

## Brand premise

**Every question is a book. Every book is a world.**

The recurring home base is **The Library of Living Questions**. The main character is a young, intelligent, curious adventurer who finds the relevant book, opens it, and enters a subject-specific world. Once inside, the visual world can change radically with the topic while the protagonist, hand-drawn visual language, and recurring brand cues maintain continuity.

The channel is intentionally general rather than psychology-only. It can cover science, history, human behavior, myths, philosophy, culture, mysteries, technology, and other worthwhile questions.

## Clothing adaptation rule

After entering a book world, the protagonist may receive a light thematic wardrobe adaptation. Preserve roughly 70–85% of the core design; change only fabric, trim, accessory details, or a modest silhouette element unless the story absolutely requires more.

Always preserve the recognizable face, hair language, subtle rounded glasses, satchel, core color family, and Page Key.
