# Default content project

This project preserves the production behavior used by every video created before content-project separation.

- Existing video directories remain under `videos/`.
- Their membership is `default`.
- The four production pipeline prompts are frozen here as project-owned copies.
- The existing `001_cinematic_storybook_green_hoodie` visual preset remains at root `visual_presets/`; this project explicitly allows that legacy fallback so the canonical images are not duplicated.

New channel/brand work should use a different content project.
