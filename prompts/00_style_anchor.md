# Prompt 00A — Style Anchor

## Purpose

Create a reusable **style anchor image** that defines the visual language for this YouTube video series.

This image is not a storyboard scene. It is a canonical visual reference that should be uploaded whenever new storyboard sheets are generated in a fresh chat/session.

## Output goal

Generate one clean reference board that demonstrates:

- illustration rendering style
- line quality
- color palette
- lighting language
- texture
- level of detail
- character rendering treatment
- environment rendering treatment
- visual metaphor style

## Prompt

Create a clean visual style reference board for an English faceless YouTube psychology explainer series.

The style should be:

- polished 2D illustrated-cartoon rendering
- cinematic but clearly illustrated, not photorealistic
- expressive faces and body language
- dark tousled-hair character treatment compatible with the recurring protagonist
- warm, readable daytime lighting
- deep blue, calm nighttime lighting
- soft painterly shading
- clean silhouettes
- moderate detail, not hyper-detailed
- uncluttered compositions
- strong visual metaphors
- cohesive storybook/editorial feel
- suitable for repeated AI generation across many scenes

The reference board should include several small example areas showing:
- a simple bedroom at night
- a daytime desk/work setting
- a close character expression
- a simple memory/thought visualization
- a simple symbolic/metaphorical object

Do not create a comic story.
Do not include panel numbers, captions, narration, subtitles, logos, or watermarks.
Do not include readable text except tiny incidental environmental details if unavoidable.

The purpose of this image is visual consistency. Keep the same rendering treatment, palette logic, line quality, and character anatomy across the entire board.
