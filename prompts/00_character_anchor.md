# Prompt 00B — Character Anchor

## Purpose

Create a reusable canonical character-reference image for the recurring adult protagonist used across storyboard sheets.

This reference should be uploaded together with the style anchor whenever a new storyboard sheet is generated in a new chat or browser session.

## Prompt

Create a clean character reference sheet for one recurring adult male protagonist in a 2D illustrated-cartoon YouTube psychology explainer style.

Canonical identity:
- adult male in his twenties
- dark tousled hair
- expressive dark eyebrows
- large readable eyes
- friendly, relatable face
- slim-to-average build
- green hoodie as the default recurring outfit
- dark pants
- no jewelry, hats, or complicated accessories

Show the exact same character consistently in several simple reference views:
- front view
- three-quarter view
- side view
- neutral expression
- embarrassed expression
- tired expression
- surprised expression

Keep face shape, hair silhouette, eyebrow shape, eye design, body proportions, hoodie design, and colors identical across every view.

Rendering:
polished 2D illustrated-cartoon look, cinematic but clearly illustrated, soft painterly shading, clean silhouettes, moderate detail, expressive but not exaggerated anatomy, cohesive storybook/editorial finish.

Use a plain neutral background.

This is a character identity reference, not a story scene.
Do not include captions, labels, panel numbers, subtitles, logos, watermarks, or explanatory text.
